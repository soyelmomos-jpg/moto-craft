# 🏍️ MOTO CRAFT

Carreras de **motos 3D estilo Minecraft** con bots de IA. Elegí entre **10 motos** diferentes, desafiá a hasta **8 bots** en una pista estilo bloque, y usá el nitro para ganar.

## ✨ Features

- 🏍️ **10 motos únicas** con estadísticas distintas (velocidad, aceleración, manejo, nitro)
- 🤖 **4 a 8 bots con IA** que toman curvas, usan nitro y compiten de verdad
- 🧱 **Pista estilo Minecraft**: bloques de asfalto, pasto, árboles, oro
- 🏁 **Sistema de vueltas** con minimapa en tiempo real
- 💨 **Sistema de nitro** con barra de combustible
- 🎮 **Controles PC + celular** (joystick táctil)
- 📊 **HUD completo**: velocidad, posición, tiempo, vueltas
- ☁️ **Nubes, sombras y obstáculos** estilo bloque

## 🎮 Cómo jugar

**PC:**
- **W / ↑**: acelerar
- **S / ↓**: frenar
- **A / D o ← / →**: girar
- **ESPACIO**: nitro
- **C**: cambiar cámara

**Celular:**
- D-pad táctil para moverte
- Botón **N** (centro) para nitro

## 🛠️ Cómo correrlo

```bash
# Opción simple: abrí index.html en el navegador
# o con servidor local:
npx http-server -p 3000 .
# Luego entrá a http://localhost:3000
```
